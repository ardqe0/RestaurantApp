# Güvenlik Politikası

## Desteklenen sürüm

Güvenlik düzeltmeleri `main` branch'indeki güncel sürüme uygulanır.

## Güvenlik açığı bildirme

Bir güvenlik açığı bulursanız ayrıntıları herkese açık issue olarak paylaşmayın.
Repository'nin **Security** sekmesindeki **Report a vulnerability** seçeneğini
kullanarak özel güvenlik bildirimi gönderin.

Bildirimde etkilenen bileşeni, sorunu yeniden oluşturma adımlarını, olası etkisini
ve varsa önerilen çözümü belirtin. Gerçek kullanıcı verisi, parola, erişim anahtarı
veya token eklemeyin.
